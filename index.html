Excel 批量合并工具

Python

多门店、多月份的报表需要手工复制汇总，耗时且容易漏行——于是写了个一键合并的命令行工具。

  • 支持 .xlsx / .xlsm / .xls / .csv 四种格式混合合并
  • 自动识别并跳过重复表头，过滤整行为空的数据
  • 每行追加“来源文件”列，合并结果可逐条溯源核对
  • 单个文件损坏或编码异常时自动跳过，最后汇总报错清单
  • 输出表冻结首行、生成筛选器、列宽自适应
  • 命令行参数控制输出路径、多工作表合并、来源列开关
# 把某个文件夹里的表全部合并
python excel_merge.py D:\报表

# 合并所有工作表，且不加来源列
python excel_merge.py D:\报表 --all-sheets --no-source

# 输出
合并完成：合并结果_20261018.xlsx
文件数：3　数据行：5　跳过：1
